vim: manual de sobrevivência

1. comandos de saída

  • ESC : garante que você não está no modo de inserção.
  • :q! : sai sem salvar.
  • :wq : salva e sai.
  • :x : similar ao :wq, mas só grava se houver alterações.

2. modos de operação

  • i : modo de inserção (escrita).
  • v : modo visual (seleção).
  • ESC : retorno ao modo de comando.

3. movimentação básica

  • h j k l : esquerda, baixo, cima, direita.
  • 0 / $ : início / fim da linha.
  • gg / G : topo / fim do arquivo.

4. edições rápidas (no modo de comando)

  • x : deleta o caractere sob o cursor.
  • dd : deleta a linha inteira.
  • u : desfaz a última ação (undo).
  • /termo : busca por um termo (n para próximo).
